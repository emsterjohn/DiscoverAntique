BUILD AND STATIC TEST REPORT
============================

IMPLEMENTED IMAGE SYSTEM
------------------------
- The only photo directory is tourist-spot-images/.
- Each attraction folder expects one local photo named image.jpg.
- No JSON manifest or manual image-path registration is required.
- Municipality carousel cards and selected municipality backgrounds use the same pool of photos belonging to that municipality.
- Each attraction detail page uses the image.jpg from that exact attraction folder.
